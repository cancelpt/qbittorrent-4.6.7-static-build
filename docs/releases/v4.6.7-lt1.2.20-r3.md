## Changes

- Adds WebUI filters and live counts for Tracker error, Other error, and Warning.
- Fixes an empty or unresponsive torrent list caused by a saved category that no longer exists. Invalid category selections automatically return to All.
- Avoids marking torrents as errored when another tracker is working.

Linux x86_64 static build based on qBittorrent 4.6.7 and libtorrent 1.2.20. Download the binary and verify it against SHA256SUMS.

## 更新

- WebUI 新增 Tracker 错误、其他错误和警告筛选，显示实时计数。
- 修复已保存分类失效导致种子列表空白或无法刷新的问题，失效选择自动恢复为“全部”。
- 存在正常工作的 Tracker 时，不再因备用地址失败而将种子归入错误筛选。

基于 qBittorrent 4.6.7 和 libtorrent 1.2.20 的 Linux x86_64 静态构建。下载后请使用 SHA256SUMS 校验。
